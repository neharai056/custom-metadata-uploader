# Custom Metadata Uploader

A simple repository for uploading custom metadata. This project is intended to store, manage, and deploy metadata configuration files or artifacts in a consistent and reusable way.

## Features

- Add, update, and manage custom metadata definitions
- Support for structured metadata storage
- Easy integration with existing deployment workflows

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/neharai056/custom-metadata-uploader.git
   cd custom-metadata-uploader
   ```

2. Add or modify metadata files as needed.

3. Commit your changes and push to the repository.
